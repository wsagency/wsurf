# WSurf — “Flux Switch”

**Idea.** A mode switch whose liquid knob stretches mid-glide into its next state: adaptable control, approachable rather than hacker-only.

**Strength.** Friendly and instantly legible. The halo gap means the silhouette survives one-colour use.

**Trade-off.** Toggles are common UI vocabulary, so it relies on the liquid knob to be ownable. The mark is wide (about 1.5:1). Use `-small.svg` at 32 px and below.

**c-slots.** c1 deep track, c2 bright track, c3 knob tail, c4 knob highlight. c5/c6 unused. Keep c1/c2 darker than c3/c4.

**Clear space.** ¼ of mark width.

**Palette.** #3B1FD1, #8A63FF, #14C79A, #D9FFF0.

**Provenance.** Authored from scratch by Claude Opus 5.5 for this task. No stock art; no HIG template.
