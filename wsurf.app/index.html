Made for everyday browsing

Keep your flow.

Familiar browser tools, with an assistant when you need one.

01

A place for every tab

Organize tabs with folders and pins. Use split view, separate profiles, and private browsing. Unload page content without losing the link.

02

Help, in context

Ask the assistant to search, read websites, and use the tabs you share. Review its actions in Agent Activity. Click the page to stop it and take over.

03

Choose your model

Use your own provider credentials, or run a local model with Ollama or LM Studio. Switch providers in Settings instead of switching browsers.

Know what you share

Browser access.
Not a blank check.

The assistant asks before purchases, sending, or signing in. Password and payment autofill are separate from the assistant.

Provider API keys are stored in macOS Keychain. Messages, shared page content, and attachments go to the model you select. A local model is an option.

Make it yours.

Build the current source with macOS 26 or later, Apple silicon, and Xcode 26.5 or later.

git clone https://github.com/wsagency/wsurf.git
cd wsurf
open WSurf.xcodeproj

Select the WSurf target and set your team in Signing & Capabilities. Some system features require additional entitlements and provisioning.
