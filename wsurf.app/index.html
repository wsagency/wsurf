Keep your flow.

Familiar browser tools, with an assistant when you need one. This is what the current source does.

Tabs and windows

Open separate windows with tabs, folders, pins, Favorites, and split view. Move a live tab to another window of the same profile without reloading it. Windows restore after relaunch.

Search your history, resume downloads, and import bookmarks from an HTML export.

Unload, undo, and folders

X removes an unpinned tab and its link. ⌘-click unloads it instead and keeps the link. Unload a whole folder in one click.

Undo or ⌘Z brings back deleted folders and removed links. Pin a folder on its own.

Command palette and previews

Type a site name or domain, then press Tab to search that site. Enter opens the results in a new tab. Option-Enter uses the current tab.

Hold Shift over a link for a summary. Shift-click it to open a preview.

The assistant

Ask in the address field, or hold ⌥Space to speak. Use @ to include a tab, and attach files. In the tabs you share, it can search, read, click, type, and scroll. Review each step in Agent Activity. Click the page to stop it.

It fills up to 32 non-sensitive fields at a time, without submitting the form. If a provider rate limit pauses it, wait, then choose Continue.

Choose your model

Use Apple Intelligence on your Mac, add a provider key, or connect a local server such as Ollama or LM Studio. Providers include OpenAI, Anthropic, Gemini, DeepSeek, Groq, Mistral, OpenRouter, and xAI.

External assistants can use WSurf's MCP server. They see only the tabs you share.

Two engines

WebKit is the default. For any website, choose embedded Chromium in Website Settings › Browser Engine.

Changing the engine reloads the website and resets its Back and Forward history. Cookies, storage, and sign-ins stay separate for each engine.

Themes and sidebar

Pick Auto, Light, Dark, Light Calm, or Dark Calm. Customize a theme and watch it update live.

Set the sidebar font, size, weight, row spacing, and folder tint. Colors are saved for each theme.

Passwords and sign-in

Fill passwords with macOS Passwords-compatible autofill. Save cards and contacts in Settings › Autofill. Unlock them with Touch ID or your Mac password. Passkeys use the macOS prompt.

You can also opt in to a Credential Manager. It keeps passwords, passkeys, and one-time codes in an encrypted store for each profile.

In the current source. Not yet verified in a signed build.

Extensions and profiles

Add WebKit extensions from the Chrome Web Store and Firefox Add-ons.

Profiles keep cookies, history, tabs, permissions, and extensions apart. Press ⇧⌘N for a private window. Closing it ends only that private session.

Read the security boundaries ↗
  • Per-site access Set assistant access for each website, and turn on its tools in Settings › Assistant.
  • It asks first The assistant asks before purchases, sending information, or signing in. It cannot fill passwords or card numbers. Browser autofill does that.
  • Your keys API keys stay in Keychain and go only to their provider. Messages, shared page content, and attachments go to the model you select.
  • Voice On-device voice turns speech into text on your Mac. OpenAI dictation and voice conversations send microphone audio to OpenAI.
  • Private windows Each has its own temporary website storage and permissions. Private browsing does not save history, tabs, or assistant transcripts.
  • Trackers WSurf blocks known third-party trackers by default. WebKit extensions can block more.

Good to know

  • There is no separate bookmarks manager. Pins and folders replace it. You can import bookmarks from an HTML export, but not history.
  • Website notifications need WSurf to be running. There is no background web push.
  • Chromium stays loaded until you quit. It does not promise lower RAM or CPU use, or faster websites.
  • Extensions and native Picture in Picture work with WebKit only.
  • Native passkeys are not guaranteed in legacy or private tabs.

Make it yours.

Build the current source with macOS 26 or later, Apple silicon, and Xcode 27.0 or later.

git clone https://github.com/wsagency/wsurf.git
cd wsurf
open WSurf.xcodeproj

Select the WSurf target and set your team in Signing & Capabilities. Some system features require additional entitlements and provisioning.
