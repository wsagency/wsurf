What changed in WSurf, newest first.

No public signed release yet. These entries describe changes merged into the source. Some are in the source only and not yet verified in a running app.

In development · merged into main

0.9.0 Candidate

Everything merged since the 0.8.0 snapshot on 8 October. This is what the current source does.

21 October 2026

  • The Tandem website is live. wsurf.app serves the new design, with the features list and this changelog. CI publishes the site after every green main push.

    Commit ad75257c ↗

  • Real Earth and Moon in the relief set. The brand kit gains an animated Earth and Moon in true NASA colors, at the Moon's real size relative to Earth, beside the Tandem-colored pair.

    Pull request #31 ↗

17 October 2026

  • A new look for wsurf.app. The website now uses the Tandem identity, and the footer credits its maker.

    Pull request #28 ↗ Pull request #29 ↗

  • Tandem brand kit. The Tandem mark replaces the earlier Flux draft, with a 3D mark, an animated loader, and a relief set. These are brand files in the repository.

    Pull request #26 ↗ Pull request #27 ↗

16 October 2026

  • Flux brand kit. A first brand design draft, with candidate art. Tandem replaced it the next day.

    Pull request #24 ↗

14 October 2026

  • Several vaults per profile. The opt-in Credential Manager can keep up to 16 vaults for each profile. Each has its own passkey unlock and its own Trash, and you can restore earlier versions of a password.

    A vault saved by an older WSurf upgrades once, with a backup, and older builds cannot open it afterward. Automated tests pass. Not yet verified by hand on a Mac.

    Pull request #19 ↗

  • Import and export. Credential Settings has one Import & Export section. Import a password CSV, or export logins to one.

    The exported file is not encrypted, and a CSV carries no passkeys or one-time codes. Only a component check of the CSV code has run, with no full build or test.

    Pull request #20 ↗

  • Profile settings and palette focus. A named profile no longer falls back to the original profile's settings. The command palette no longer takes keyboard focus back after you move it.

    Pull request #19 ↗

11 October 2026

  • Opt-in Credential Manager. Passwords, passkeys, and one-time codes can live in an encrypted store for each profile, unlocked by a passkey. Passwords stays the default provider.

    In the source and not released. Native passkey unlock and Apple Passwords transfers are not yet verified.

    Pull request #14 ↗

  • Passkey entitlement removed. WSurf no longer requests Apple's managed browser passkey entitlement. Native passkeys are not guaranteed in legacy or private tabs.

    Pull request #17 ↗

10 October 2026

  • Extension windows. A retired extension window is replaced with a fresh one instead of being reused.

    Pull request #15 ↗

9 October 2026

  • Engine in the address bar. The address bar shows WK or Cr beside the lock for the engine that loaded the page: WebKit or Chromium.

    Pull request #11 ↗

  • Provider keys in Keychain. Provider, MCP, and OAuth credentials now use the classic macOS Keychain. Deleted credentials stay deleted.

    Pull request #10 ↗

0.8.0

The first numbered snapshot of WSurf, taken 8 October 2026: profiles, embedded Chromium, the assistant, themes, and the sidebar.

8 October 2026

  • Windows and profiles. Windows know their profile. Move a live tab between windows of the same profile on WebKit and Chromium. Each private window keeps its own session.

    3,016 native tests passed. Some manual checks remain.

    Pull request #8 ↗

  • Assistant limits and recovery. The assistant fills up to 32 fields in one step without submitting. After a provider rate limit it pauses, and you choose Continue without repeating finished actions.

    Pull request #8 ↗

  • Command palette and opening apps. Press Tab after a site name to search that site. WSurf remembers your approval to open an app from a website, for that website and app. Revoke it in Website Settings › Opening apps.

    Pull request #8 ↗

  • Smaller improvements. WebKit PDFs save through Downloads, saved scroll positions come back after late page resets, idle players stop polling, and Window and Dock titles stop at 40 characters. The full list of 31 changes from Linen is in CHANGELOG.md.

    Pull request #8 ↗ Pull request #9 ↗

6 October 2026

  • Embedded Chromium. Choose WebKit or embedded Chromium for each website in Website Settings › Browser Engine. Chromium starts only when needed. Extensions and native Picture in Picture stay WebKit-only.

    Pull request #4 ↗

  • Sidebar controls. X removes an unpinned tab and its link, and ⌘-click unloads it instead. A folder's arrow unloads everything inside it. Folders can be pinned on their own.

    Pull request #3 ↗ Pull request #4 ↗ Pull request #5 ↗

  • Favorites, Undo, and new folders. Favorites are an icon-only strip for each profile. Undo restores deleted folders and removed links. A new folder opens ready for its name.

    Pull request #5 ↗

  • Themes and sidebar look. Light Calm and Dark Calm join the themes. Customize a theme live, and set the sidebar font, size, weight, row spacing, and folder tint.

    Pull request #3 ↗ Pull request #4 ↗ Pull request #5 ↗

  • omp.sh. WSurf can set up omp.sh as an external assistant over MCP, with automatic CLI detection.

    Pull request #3 ↗

  • Housekeeping. The website deploys after CI passes on main, CI formatting is fixed, and session worktrees are configured.

    Pull request #2 ↗ Pull request #6 ↗ Pull request #7 ↗

5 October 2026

  • Move to Folder follows the sidebar. The menu nests like your folders instead of listing every folder at the first level.

    Commit fd0edca ↗

  • Downloads. A repeated or late handoff of the same download no longer creates a duplicate transfer.

    Commit e6362ec ↗

  • First website. The first version of the wsurf.app website, with a domain association file for the app.

    Commit 7591eb4 ↗

  • Working rules. Changes to main now go through feature worktrees and pull requests.

    Pull request #1 ↗

4 October 2026

  • WSurf starts as a fork of Linen. It has its own name, app identity, data folder, and artwork, and keeps the Apache 2.0 license and credits.

    Commit c4c4055 ↗

0.7.1 and earlier

Early WSurf work is tagged v0.7.1 on GitHub. WSurf began as a fork of Linen by Kavoye. Linen's inherited release notes are in CHANGELOG.md on GitHub. They describe Linen releases, not WSurf releases.

CHANGELOG.md also keeps the detailed WSurf notes.
