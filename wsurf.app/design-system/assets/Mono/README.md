# Mono

Tandem in one ink. The gap between the discs carries the two parts.

- `mark-mono.svg`, `mark-mono-tight.svg`, `mark-mono-small.svg`, `lockup-mono.svg`: ink `currentColor` (black in an `<img>`; inline and set `color`).
- `mark-black.svg`, `mark-black-tight.svg`, `lockup-black.svg`: ink `#1D1D1F`, for light grounds and print.
- `mark-white.svg`, `mark-white-tight.svg`, `lockup-white.svg`: ink `#F5F5F7`, for dark grounds.
