# Dock finishes

WSurf uses the Anodized Tandem icon in its application bundle. In Settings → Appearance → Dock icon, **Default** follows the Mac’s icon appearance. **Anodized** pins the same artwork to its fixed finish. The other fixed choices are Steel, Copper, Light, Dark and Mono. Finder uses the bundle icon. A user’s choice takes effect in the Dock while WSurf is running.
