# Lockup

Tandem mark plus the "WSurf" wordmark. Wordmark outlines: Inter Display Bold, Copyright (c) 2016 The Inter Project Authors (https://github.com/rsms/inter), SIL Open Font License 1.1 (full licence text in `Inter-OFL.txt` beside this README); tracking −0.04em, the font's kerning, the f moved 104 units right. WSurf artwork is licensed under BUSL-1.1 (see `NOTICE`).

- `lockup-light.svg`: mark in Day inks, wordmark `#1D1D1F`. For light grounds.
- `lockup-dark.svg`: mark in Night inks, wordmark `#F5F5F7`. For dark grounds.
- `lockup.svg`: mark from `--wsurf-lead` / `--wsurf-follower`, wordmark `currentColor` (black in an `<img>`; inline it and set `color: var(--ink)`).
- `wordmark-light.svg`, `wordmark-dark.svg`, `wordmark.svg` (`currentColor`): the wordmark alone, for places where the mark already appears nearby.
- `Inter-OFL.txt`: upstream SIL Open Font License 1.1 text for the outlined Inter Display Bold wordmark.

Proportions: mark 1.22× cap height, gap 0.25× cap height, waterline 1.6% of the mark height below the baseline, aspect 4.55:1. Clear space is the follower's diameter on every side. Minimum 24px tall.
